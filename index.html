Regras

Sistema Pontos corridos.
Sorteios Sorteios semanais, evitando repetição enquanto houver confrontos inéditos.
Prazo 15 dias corridos para realizar a partida, sem extensão excepcional.
Formato Melhor de 3 sets.
3º set Em caso de 1x1, Match Tiebreak até 10 pontos, com diferença mínima de 2.
Pontuação Cada set vencido vale 1 ponto. Vitória 2x0 = 2 pontos para o vencedor e 0 para o perdedor. Vitória 2x1 = 2 pontos para o vencedor e 1 para o perdedor.
W.O. Quem recebe o W.O. soma 1 ponto. Quem concede soma 0.
Responsável pelo W.O. Se o jogo não ocorrer em 15 dias, concede o W.O. quem menos disponibilizou horários ou menos colaborou para a realização da partida.
Desempate 1º confronto direto → 2º saldo de sets → 3º saldo de games → 4º games ganhos.
Encerramento Ranking congelado em 15/11/2026.
Finals 1º x 4º e 2º x 3º nas semifinais. Perdedores disputam o 3º lugar. Vencedores disputam a final.
